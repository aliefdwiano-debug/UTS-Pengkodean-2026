# 3.1a Orkestrasi AI Tools: Gemini Canvas

Hasil di Gemini Canvas: https://share.gemini.google/ogaMgNqmlCXX

File hasil: `voucher_kas_keluar.html` (di folder ini).

## Prompt yang digunakan

**Prompt 1 (membuat kerangka)**
Buatkan satu file HTML dengan Tailwind CSS (CDN) dan JavaScript murni untuk formulir Voucher Entri Transaksi Kas Keluar. Field header: tanggal, nomor bukti, deskripsi. Bagian detail berupa tabel jurnal dinamis dengan kolom akun (dropdown), debit, kredit, dan tombol hapus baris. Sediakan tombol tambah baris.

**Prompt 2 (live balanced indicator)**
Tambahkan total debit, total kredit, dan selisih yang dihitung otomatis setiap kali nilai berubah. Tampilkan indikator hijau 'SEIMBANG' jika total debit sama dengan total kredit dan lebih dari 0, dan merah 'TIDAK SEIMBANG' beserta selisihnya jika tidak. Hitung dalam satuan sen (integer) untuk menghindari galat pembulatan.

**Prompt 3 (aturan bisnis)**
Tombol Submit harus disabled sampai: jurnal seimbang, minimal 2 baris, setiap baris hanya boleh diisi salah satu sisi (debit atau kredit, tidak boleh keduanya), tanggal dan nomor bukti terisi. Untuk voucher kas keluar, minimal satu baris harus mengkredit akun Kas.

**Prompt 4 (audit)**
Saat Submit, bentuk payload JSON berisi header dan lines, lalu siapkan pemanggilan supabase.rpc('post_cash_voucher', payload). Tambahkan komentar tempat memasang Supabase URL dan anon key.
